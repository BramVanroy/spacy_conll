    Formatter¶

    spacy_conll.formatter ¶

    The conll_formatter pipeline component.

    ConllFormatter dataclass ¶

    ConllFormatter(
    conversion_maps: dict[str, dict[str, str]]
    | None = None,
    ext_names: dict[str, str] = dict(),
    field_names: dict[str, str] = dict(),
    include_headers: bool = False,
    disable_pandas: bool = False,
    columns: list[str] | None = None,
)

    spaCy component that adds CoNLL-U representations to docs, sentences and tokens.

    The extension conll holds a dict of field names to values on a Token, a list of those dicts on a sentence Span, and a list of sentence lists on a Doc. The extension conll_str holds the tab-separated CoNLL-U text, and conll_pd (when pandas is installed and disable_pandas is false) holds a pandas Series or DataFrame. The pandas object is built from conll on access and is not stored in the doc, so docs can be saved with DocBin and sent between processes. Multi-word tokens and empty nodes are not supported.

    Parameters:

    Name Type Description Default
    conversion_maps dict[str, dict[str, str]] | None

    Maps a field name to a map of output values, for example {"LEMMA": {"-PRON-": "PRON"}} replaces the lemma -PRON- with PRON.

    		 None
    ext_names dict[str, str]

    New names for the extensions conll, conll_str and conll_pd, for example {"conll": "conll_dict"}.

    		 dict()
    field_names dict[str, str]

    New names for the CoNLL-U fields ID, FORM, LEMMA, UPOS, XPOS, FEATS, HEAD, DEPREL, DEPS and MISC, for example {"UPOS": "upostag"}.

    		 dict()
    include_headers bool

    Whether conll_str of a sentence starts with the # sent_id and # text comment lines.

    		 False
    disable_pandas bool

    Whether to skip the conll_pd extension even if pandas is installed.

    		 False
    columns list[str] | None

    The CoNLL-U Plus columns to write, in this order. None uses Doc._.conll_columns if the doc has it (a doc that was read from CoNLL-U Plus text), and plain CoNLL-U otherwise. With columns, conll_str of the doc starts with a # global.columns line. The names are the CoNLL-U names (also when field_names renames them) or custom names such as PARSEME:MWE. A custom column takes its value from the dict in Token._.conll_custom_columns, and is _ when the dict does not have it.

    		 None

    Examples:

    import spacy
nlp = spacy.blank("en")
_ = nlp.add_pipe("sentencizer")
_ = nlp.add_pipe(
    "conll_formatter", config={"include_headers": True}
)
doc = nlp("Hello world.")
doc[1]._.conll
# {'ID': 2, 'FORM': 'world', 'LEMMA': '_', 'UPOS': '_', 'XPOS': '_',
#  'FEATS': '_', 'HEAD': '_', 'DEPREL': '_', 'DEPS': '_',
#  'MISC': 'SpaceAfter=No'}
print(doc._.conll_str.replace("\t", " "))
# # sent_id = 1
# # text = Hello world.
# 1 Hello _ _ _ _ _ _ _ _
# 2 world _ _ _ _ _ _ _ SpaceAfter=No
# 3 . _ _ _ _ _ _ _ SpaceAfter=No

    get_whitespace_misc ¶

    get_whitespace_misc(token: Token) -> str

    Describe the whitespace around a token in the MISC notation of UD.

    The whitespace after a token is its own trailing space plus the text of the whitespace tokens that follow it, also when these tokens belong to the next sentence. A single space gives _, no whitespace gives SpaceAfter=No and anything else gives SpacesAfter with the escapes \s, \t, \n and \r. Whitespace at the start of the doc gives SpacesBefore on the first token that is not whitespace. See https://universaldependencies.org/misc.html.

    Parameters:

    Name Type Description Default
    token Token

    A token that is not whitespace.

    		 required

    Returns:

    Type Description
    str

    The MISC value.

    Examples:

    import spacy
doc = spacy.blank("en")("\nHello  world.\t")
[t.text for t in doc]
# ['\n', 'Hello', ' ', 'world', '.', '\t']
[get_whitespace_misc(t) for t in doc if not t.is_space]
# ['SpacesAfter=\\s\\s|SpacesBefore=\\n', 'SpaceAfter=No', 'SpacesAfter=\\t']

    merge_misc ¶

    merge_misc(misc: str, whitespace_misc: str) -> str

    Replace the whitespace entries in a MISC value and keep the others.

    The entries SpaceAfter, SpacesAfter and SpacesBefore of misc are replaced by those of whitespace_misc in the same position, or removed when whitespace_misc has no such entry. New whitespace entries go at the end. spaCy stores the whitespace after a token as a single space or nothing, so an existing SpacesAfter (for example read from a CoNLL-U file) stays when the token is followed by a single space. An existing SpacesBefore stays when whitespace_misc has none.

    Parameters:

    Name Type Description Default
    misc str

    The current MISC value, _ if empty.

    		 required
    whitespace_misc str

    The output of get_whitespace_misc.

    		 required

    Returns:

    Type Description
    str

    The merged MISC value, _ if empty.

    Examples:

    merge_misc("Translit=a|SpaceAfter=No", "_")
# 'Translit=a'
merge_misc("Translit=a", "SpaceAfter=No")
# 'Translit=a|SpaceAfter=No'
merge_misc("SpacesAfter=\\n|Translit=a", "_")
# 'SpacesAfter=\\n|Translit=a'
merge_misc("SpacesAfter=\\n|Translit=a", "SpaceAfter=No")
# 'Translit=a|SpaceAfter=No'
merge_misc("SpacesBefore=\\n|Translit=a", "_")
# 'SpacesBefore=\\n|Translit=a'

    parse_text_as_conll ¶

    parse_text_as_conll(
    text: str,
    *,
    n_process: int = 1,
    renumber_sent_ids: bool = True,
    ignore_pipe_errors: bool = False,
    split_on_newline: bool = True,
    sent_ids: Iterable[str | int] | None = None,
) -> str

    Parse a text and return its CoNLL-U representation.

    Each line is a separate doc in nlp.pipe, so # sent_id would restart at 1 for every line. With renumber_sent_ids, the sentences are numbered 1, 2, 3 and so on over the whole text instead. This only matters when the formatter has include_headers=True. With sent_ids, the sentences get your own IDs instead, in order of the output.

    Parameters:

    Name Type Description Default
    text str

    The text to parse.

    		 required
    n_process int

    Number of processes for nlp.pipe. -1 uses all cores. Values other than 1 may not work with UDPipe.

    		 1
    renumber_sent_ids bool

    Whether to number # sent_id consecutively over the whole text.

    		 True
    ignore_pipe_errors bool

    Whether to skip the checks that raise an OSError when n_process is likely to fail on this system.

    		 False
    split_on_newline bool

    Whether to split the text on newlines and pass every line to nlp.pipe separately. This is faster for long texts.

    		 True
    sent_ids Iterable[str | int] | None

    One ID per output sentence for the # sent_id lines. An ID cannot be empty or contain whitespace. It replaces the generated numbers and renumber_sent_ids has no effect. Requires include_headers=True in the formatter. With disable_sbd=True in init_parser, every input line is one sentence, so you can give one ID per line.

    		 None

    Returns:

    Type Description
    str

    The CoNLL-U string, with one empty line between sentences. It
    str

    starts with a # global.columns line when the formatter has
    str

    columns.

    Raises:

    Type Description
    OSError

    If n_process is not 1, ignore_pipe_errors is false, and the backend is UDPipe on Windows.
    ValueError

    If sent_ids is given without include_headers, if an ID is empty or contains whitespace, or if the number of IDs differs from the number of sentences.

    parse_conll_text_as_spacy ¶

    parse_conll_text_as_spacy(
    text: str,
    *,
    ner_tag_pattern: str = NER_TAG_PATTERN,
    ner_map: dict[str, str] | None = None,
    strict: bool = True,
) -> Doc

    Read CoNLL-U text into a spaCy doc.

    Sentences are separated by an empty line, and every sentence block becomes one spaCy sentence. Fields that spaCy does not store are kept in extensions: DEPS in Token._.conll_deps_graphs_field, MISC in Token._.conll_misc_field and the comment lines in Span._.conll_metadata of the sentence. A _ in LEMMA, UPOS, XPOS or FEATS leaves that attribute empty in spaCy, and the formatter writes _ again. Multi-word tokens and empty nodes are not supported. Adapted from spaCy's conllu2json converter.

    With strict=False, HEAD and DEPREL may be _ (both on the same line), for example in a file that is tagged but not parsed. Such a token has no head in spaCy (token.has_head() is false and token.dep_ is ""), and the formatter writes _ for both fields. The HEAD values of a sentence then do not have to form one tree.

    CoNLL-U Plus is supported: when the first line is a # global.columns comment, the lines have these columns in this order. A standard column that is missing gets the value _, and an ID column that is missing gets the token position. Custom columns such as PARSEME:MWE are kept in the dict Token._.conll_custom_columns. The # global.columns line is not part of Span._.conll_metadata. The columns are stored in Doc._.conll_columns, which the formatter uses to write the doc again unless it has its own columns.

    Parameters:

    Name Type Description Default
    text str

    CoNLL-U text.

    		 required
    ner_tag_pattern str

    Regex for the entity tag in the MISC field.

    		 NER_TAG_PATTERN
    ner_map dict[str, str] | None

    Maps old entity labels to new ones. A label that maps to "" becomes O.

    		 None
    strict bool

    Whether every token needs a HEAD and a DEPREL, and the HEAD values of every sentence must form one tree.

    		 True

    Returns:

    Type Description
    Doc

    A doc with all sentences of the text and the CoNLL extensions.

    Raises:

    Type Description
    ValueError

    If a line does not have 10 fields (or as many as the # global.columns line lists), a field is empty, a field other than FORM, LEMMA, MISC or a custom column contains a space, ID or HEAD is not a valid number, only one of HEAD and DEPREL is _, or # global.columns has an invalid column name. With strict=True also if HEAD or DEPREL is _, or if the HEAD values of a sentence do not form one tree. The message starts with the line number.
    NotImplementedError

    If the text has multi-word tokens or empty nodes.

    Examples:

    import spacy
nlp = spacy.blank("en")
_ = nlp.add_pipe(
    "conll_formatter", config={"include_headers": True}
)
conll = "\n".join(
    [
        "# sent_id = a1",
        "1\tHi\thi\tINTJ\tUH\t_\t0\troot\t0:root\t_",
        "2\tthere\tthere\tADV\tRB\t_\t1\tadvmod\t1:advmod\tSpaceAfter=No",
    ]
)
doc = ConllParser(nlp).parse_conll_text_as_spacy(conll)
[(t.text, t.dep_, t.head.text) for t in doc]
# [('Hi', 'ROOT', 'Hi'), ('there', 'advmod', 'Hi')]
print(doc._.conll_str.replace("\t", " "))
# # sent_id = a1
# 1 Hi hi INTJ UH _ 0 root 0:root _
# 2 there there ADV RB _ 1 advmod 1:advmod SpaceAfter=No

    A sentence without dependency annotation needs strict=False:

    conll = "1\tHi\thi\tINTJ\tUH\t_\t_\t_\t_\t_"
doc = ConllParser(nlp).parse_conll_text_as_spacy(
    conll, strict=False
)
[(t.text, t.dep_, t.has_head()) for t in doc]
# [('Hi', '', False)]
print(doc._.conll_str.replace("\t", " "))
# # sent_id = 1
# # text = Hi
# 1 Hi hi INTJ UH _ _ _ _ _
